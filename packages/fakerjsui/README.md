# @faker-js-ui/app

Quasar/Vue 3 application for Faker.js UI - serves as both a web SPA and Chrome browser extension.

## Development

See the [root README](../../README.md) for development instructions.

## Modes

- **SPA Mode**: Standalone web app at `pnpm dev:app`
- **BEX Mode**: Chrome browser extension at `pnpm dev:bex`
